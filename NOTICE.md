# Notices and credits

This project is a browser implementation of ELIZA with the DOCTOR script. It was written from the specification in `eliza-spec.md`, not by copying the original program's code.

## ELIZA and the DOCTOR script

ELIZA and the DOCTOR script were created by Joseph Weizenbaum at MIT (1964-1966) and described in "ELIZA — A Computer Program for the Study of Natural Language Communication between Man and Machine", *Communications of the ACM*, vol. 9, no. 1 (January 1966).

The original MAD-SLIP source code and DOCTOR script were rediscovered in Weizenbaum's papers at MIT and released as open source with the permission of his estate. See https://github.com/rupertl/eliza-ctss and https://dome.mit.edu/handle/1721.3/201699. Some response wording in this project matches the original DOCTOR script.
